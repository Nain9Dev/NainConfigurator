# Asset boundary

This directory is reserved for the controlled 3D asset pipeline.

## Source assets

- Author with the pinned Blender 4.5 LTS patch and recorded export profile.
- Record ownership and commercial-use license for every model, texture, font, HDRI and add-on.
- Never include credentials, personal data, customer-confidential material or unreviewed downloads.

## Published assets

- Export sanitized glTF/GLB 2.0 packages.
- Validate with the pinned Khronos glTF Validator.
- Enforce naming, polygon, texture and compressed-transfer budgets.
- Publish immutable content-addressed packages only.

Large binary assets require a separate Git LFS/free-tier decision before they are committed.
