# Renderer boundary

This directory is reserved for the future Babylon.js adapter and optional browser 3D projection.

The renderer:

- Receives generic catalog codes and `visualAssetKey` mappings.
- Uses validated glTF/GLB 2.0 product packages.
- Never owns business rules, authoritative price, personal data or API credentials.
- Is lazy-loaded and replaceable behind the approved TypeScript adapter.
- Cannot block catalog, validation, save or quote behavior.
